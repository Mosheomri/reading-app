# 📖 שיעור קריאה מותאם

אתר חינמי לבניית שיעורי קריאה מותאמים בעברית.
המורה בונה שיעור בעזרת צ׳אט הבינה המלאכותית שלה (ChatGPT, Gemini או כל צ׳אט אחר), ושולחת לילד קישור.
הילד משחק, קורא ועונה על שאלות. אין צורך בהרשמה, ואין שרת שמקבל או שומר מידע.

## איך בונים שיעור (למורה)

1. **הגדרות:** כתבו נושא, בחרו את אורך הסיפור ואת מילות היעד. אפשר לתת לבינה לבחור את מילות היעד או לכתוב אותן בעצמכם. בחרו גם איך יוצג הניקוד לילד:
   - **מלא:** כל הטקסט מנוקד.
   - **חלקי:** רק מילות היעד מנוקדות.
   - **בלי ניקוד.**
2. **פרומפט:** לחצו על **"העתק"**, הדביקו בצ׳אט של הבינה שלכם ושלחו.
3. **תשובה:** הבינה תחזיר בלוק קוד. העתיקו אותו בכפתור ההעתקה שמעל הבלוק והדביקו באתר. אין צורך לנקות את התשובה, האתר מוצא את החלק הרלוונטי בעצמו. אם הבינה יצרה קובץ, אפשר לטעון אותו בכפתור **"טעינת קובץ"**.
   אם הבינה הכניסה אימוג׳י לתוך הסיפור, האתר מסיר אותם ומציג על כך הודעה.
   אם משהו חסר או שגוי, האתר יכתוב מה הבעיה ויציע **הודעת תיקון** מוכנה לשליחה לבינה. אפשר גם להמשיך ולתקן בעצמכם.
4. **עריכה:** בצד אחד רואים את השיעור כפי שהילד יראה אותו, ובצד השני אפשר לערוך הכל: הכותרת, הסיפור (כולל הניקוד), מילות היעד והאימוג׳י, השאלות והתשובות. מילות היעד מודגשות בסיפור.
5. **קישור:** לחצו על **"העתק קישור"** או **"שלח בוואטסאפ"**. כדאי לבדוק את השיעור קודם בלחיצה על **"פתח לבדיקה"**.
   מומלץ גם להוריד את **קובץ השיעור** כגיבוי. כך אפשר לטעון אותו מחדש בעמוד הראשון ולערוך אותו בעתיד.

> 💡 אם תשובת הבינה נקטעה באמצע, כתבו לה "המשך" והדביקו את כל התשובה מההתחלה ועד הסוף.

## מה הילד עושה

השיעור מתקדם בסדר קבוע, ופס התקדמות מוצג למעלה:

1. **משחקים** עם מילות היעד:
   - **זוגות:** מתאימים בין מילה לתמונה.
   - **הרכבת מילה:** בונים את המילה מאותיות מעורבבות.
   - **שומעים ובוחרים:** שומעים מילה ובוחרים אותה. המשחק הזה מופיע רק במכשירים שיש בהם קול עברי.
2. **קריאה:** הסיפור עם מילות היעד מודגשות. אפשר להגדיל ולהקטין את הטקסט, ובמכשירים שיש בהם קול עברי אפשר גם ללחוץ על מילה ולשמוע אותה.
3. **תרגילים:** שאלות אמריקאיות, נכון ולא נכון, השלמת מילה וסידור משפטים.
4. **סיום:** "כל הכבוד!" וכוכבים.

אין צלילי "טעות" ואין לחץ זמן. אחרי טעות מופיע רמז עדין ואפשר לנסות שוב, ובכל שאלה יש כפתור להצצה בסיפור.

## פרטיות

- השיעור כולו שמור **בתוך הקישור עצמו**, בחלק שאחרי הסימן `#`. החלק הזה לא נשלח לשום שרת.
- אין הרשמה, אין עוגיות, אין מעקב ואין סטטיסטיקות.
- בעמוד המורה נשמרים בדפדפן שלכם בלבד הגדרות הטופס האחרונות וטיוטת השיעור האחרון, כדי שאפשר יהיה להמשיך מאיפה שהפסקתם.
- הקריאה היחידה לרשת היא לטעינת הגופן (Google Fonts). בלעדיה האתר עובד עם גופן המערכת.

## שיעור לדוגמה

בקובץ [samples/sample-lesson.json](samples/sample-lesson.json) יש שיעור מוכן בנושא "הכלב בגינה". כדי לנסות אותו, לחצו בעמוד הראשון על **"טעינת קובץ שיעור"** ובחרו בקובץ.

## למפתחים

אתר סטטי: HTML, CSS ו-JavaScript רגיל, בלי שלב בנייה ובלי ספריות חיצוניות (LZ-String שמורה בתוך הפרויקט).

```
index.html            עמוד המורה
play.html             עמוד הילד
css/style.css
js/prompt.js          תבנית הפרומפט (כאן משנים את הנוסח)
js/builder.js         תהליך המורה
js/player.js          תהליך הילד
js/games/*.js         משחק בכל קובץ
js/exercises.js       תרגילים
js/hebrew.js          ניקוד: הסרה, נרמול, התאמת מילים עם תחיליות
js/lesson.js          בדיקת תקינות, קידוד ופענוח של הקישור
js/render.js          תצוגת טקסט משותפת למורה ולילד
js/util.js            עזרים: DOM, העתקה, הקראה
js/lz-string.min.js   LZ-String 1.5.0 (רישיון MIT)
```

**הרצה מקומית:** מריצים `python -m http.server` בתיקיית הפרויקט וגולשים אל `http://localhost:8000`.

**פרסום ב-GitHub Pages:** מעלים את התיקייה למאגר, ובהגדרות המאגר בוחרים *Pages*, ואז *Deploy from a branch* ואת הענף הראשי עם התיקייה `/`.
