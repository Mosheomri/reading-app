# Encouragement recordings

Put the recordings here: `praise-01.mp3` … `praise-08.mp3` (after a right answer) and `try-01.mp3` … `try-04.mp3`
(after a wrong answer). Each file says the text of the sentence with the same number in `js/praise.js`.
MP3, mono, 1–2 seconds, silence trimmed. No code change is needed: a file that is here is played; a missing one
falls back to the browser's Hebrew voice, or to text only. See the README of the project.
