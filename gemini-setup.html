✨ מפתח חינמי ל-Gemini

עם מפתח של Gemini, האתר כותב את השיעור ובודק אותו בעצמו: לוחצים על "✨ צור שיעור" ומחכים. את המפתח יוצרים פעם אחת, בחינם, ב-Google AI Studio. בלי מפתח אפשר תמיד להמשיך בהעתק-הדבק, עם כל צ׳אט.

  1. נכנסים ל-Google AI Studio

    פותחים את עמוד המפתחות ב-Google AI Studio ומתחברים עם חשבון Google. בכניסה הראשונה מאשרים את תנאי השימוש.

  2. יוצרים מפתח

    1. לוחצים על "Create API key" (יצירת מפתח).
    2. אם מתבקשים לבחור פרויקט, בוחרים את הפרויקט שמוצע (או יוצרים חדש) ומאשרים.
    3. המפתח מופיע ברשימה: מחרוזת ארוכה של אותיות ומספרים באנגלית. לוחצים על כפתור ההעתקה שלידו.

    אין צורך בכרטיס אשראי. המפתח החינמי מוגבל במספר הבקשות לדקה וליום; את המגבלות המדויקות רואים ב-AI Studio. לשיעור אחד צריך שתי בקשות בלבד (כתיבה ובדיקה).

  3. מדביקים את המפתח באתר

    1. חוזרים לבניית שיעור, ובשלב 1 פותחים את "✨ יצירה אוטומטית עם Gemini".
    2. מדביקים את המפתח בשדה ולוחצים על "בדוק מפתח". אם הכל תקין, המפתח נשמר בדפדפן הזה ומופיע הכפתור "✨ צור שיעור".

  4. (לא חובה) מגבילים את המפתח לאתר הזה

    כך גם אם מישהו יעתיק את המפתח, הוא לא יעבוד באתר אחר.

    1. פותחים את עמוד ה-Credentials ב-Google Cloud, ובוחרים למעלה את אותו פרויקט.
    2. לוחצים על שם המפתח.
    3. תחת "Application restrictions" בוחרים "Websites", ומוסיפים את הכתובת mosheomri.github.io/*
    4. תחת "API restrictions" משאירים רק את Generative Language API (ב-AI Studio זה נקרא "Restrict to Gemini API only").
    5. לוחצים "Save". השינוי יכול לקחת כמה דקות.

    אחרי ההגבלה המפתח יעבוד רק מהאתר הזה, ולא מתוכנות אחרות או מהמחשב של מפתח האתר.

שמירה על המפתח

  • המפתח נשמר רק בדפדפן שלכם (ב-localStorage), ונשלח רק ל-Google. הוא לא נשלח לשום מקום אחר.
  • אל תשמרו מפתח במחשב משותף (למשל בחדר המורים). אם השתמשתם בו, לחצו על "מחק מפתח" בסוף.
  • אם המפתח דלף, מוחקים אותו ב-AI Studio ויוצרים חדש.

פרטיות

  • במסלול החינמי Google רשאית להשתמש בתוכן הבקשות כדי לשפר את המוצרים שלה. אל תכתבו בנושא השיעור פרטים מזהים על ילד (שם מלא, בית ספר, מידע רפואי או אישי).
  • לבינה נשלחים רק ההגדרות של השיעור (נושא, רמה, אורך, מילים) והטקסט של השיעור לבדיקה.

אם משהו לא עובד

  • "המפתח לא תקין": ודאו שהעתקתם את כל המפתח, בלי רווחים. אם הגבלתם אותו לאתר, בדקו שהכתובת נכתבה נכון.
  • "נגמרה המכסה": המסלול החינמי מוגבל לדקה וליום. חכו כמה דקות, או נסו מחר.
  • תמיד אפשר להמשיך בהעתק-הדבק: הפרומפט מוכן בשלב 2, לכל צ׳אט.
